# 📊 Módulo 10 – Monitorando o SQL Server

## 📖 Sobre o módulo

Este módulo é dedicado ao monitoramento, diagnóstico e análise de desempenho do SQL Server.

## 🎯 Objetivos de aprendizagem

- Monitorar CPU, memória e disco.
- Utilizar DMVs.
- Interpretar Wait Statistics.
- Configurar Extended Events.
- Administrar o Query Store.

## 🛠 Tecnologias

- SQL Server
- SSMS
- Performance Monitor
- DMVs
- Activity Monitor
- Extended Events
- Query Store

## 🔍 Fluxo de Troubleshooting

```text
Problema → PerfMon → CPU/Memória/Disco → DMVs → Wait Statistics → Activity Monitor → Extended Events → Query Store → Causa raiz
```

## 📈 Competências

- Diagnóstico de desempenho
- Investigação de consultas
- Monitoramento de SQL Server
- Troubleshooting

## 🎯 Conclusão

Este módulo consolidou conhecimentos sobre monitoramento e diagnóstico de desempenho no SQL Server, com foco em ferramentas e técnicas utilizadas por DBAs em ambientes de produção.
