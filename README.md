# 📌 Sobre o projeto

Este repositório documenta minha jornada prática de aprendizado em **Microsoft SQL Server**, reunindo laboratórios, scripts, documentação técnica e projetos desenvolvidos ao longo da trilha **SQL Server Expert — SQL Server On-Premise**.

O objetivo foi construir uma base progressiva em Administração de Banco de Dados, começando pelos fundamentos de infraestrutura e SQL Server e avançando para temas como segurança, automação, concorrência, performance, alta disponibilidade, disaster recovery e replicação.

O portfólio foi estruturado para demonstrar não apenas conhecimento conceitual, mas também **prática com T-SQL, administração, troubleshooting e cenários próximos de ambientes corporativos**.

### 🎯 Direcionamento profissional

- 🗄️ DBA SQL Server Júnior
- 📊 Analista de Banco de Dados
- ⚙️ Analista de Infraestrutura de Dados
- 📈 Analista de Dados com foco em SQL Server
- 🚀 Base técnica para evolução para posições de maior senioridade em Database Administration

> **Importante:** os níveis Júnior, Pleno e Sênior indicados abaixo representam o **nível de complexidade e maturidade do conteúdo estudado na trilha**, e não uma certificação ou garantia de senioridade profissional.

| Nível | Significado |

> A classificação é uma **referência didática de dificuldade**. Um profissional pode estudar um módulo avançado sem necessariamente possuir experiência profissional equivalente ao nível indicado.
